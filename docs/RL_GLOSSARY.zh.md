# 强化学习术语表（对着这只手看）

这份表故意写短。每个词都用「Apex 指背滚币」当例子。界面「工具」页有更短的一版。

## 环境、策略、观测、动作

- **环境 (env)**：仿真里的一只手 + 一枚硬币（或两颗球）。它接收动作，返回下一帧的观测和奖励。
- **策略 (policy)**：一张神经网络。输入观测，输出 16 个主动关节该怎么动。
- **观测 (observation)**：策略看见的数字。默认是关节位置/速度、物体位姿、指尖位置、上一步动作。**不是**相机画面（除非你开了 Vision 任务）。
- **动作 (action)**：`[-1, 1]^16`，表示相对默认指背姿态的增量。5 个耦合关节由代码写透，策略不管。

## 奖励、一局、价值

- **奖励 (reward)**：每一步的打分。策略最大化的是「折扣后的未来奖励之和」，不是某一步。
- **奖励项**：很多小分加起来。`drop=-10` 和 `joint_vel_l2=-2.5e-5` 差了几个数量级是故意的——后者只是微调。
- **一局 (episode)**：从重置到掉落 / 成功 / 超时。Hold 默认 3 秒。
- **价值函数 (critic)**：另一张网络，猜「从现在起还能拿多少分」。PPO 用它来减方差。

## PPO 里你会碰到的旋钮

- **学习率**：一次更新迈多大。本仓库默认 **adaptive**：KL 太大就自动把学习率拧小。
- **γ (gamma)**：未来奖励打几折。有效视野约 `1/(1-γ)` 步。0.998 ≈ 500 步，比 Hold 的 180 步还长，所以 Hold 可以试 0.99。
- **λ (GAE)**：优势估计的平滑程度。保持 0.95 即可。
- **clip ε**：一次更新不允许策略概率比偏得太远。
- **熵系数**：鼓励继续随机探索。掉到 0.01 以下，策略基本锁死了。
- **KL**：这次更新让策略分布变了多少。长期大于目标 KL 的两倍，步子太大。
- **并行环境数**：同时仿真多少只手。数据更快，显存也更贵。12 GB 无相机从 512 起步。

## 域随机化与 Sim2Real

- **域随机化**：每个环境用略不同的质量、摩擦、PD 刚度。逼策略别背下「这一个仿真硬币」。
- **PhysX vs Newton/MuJoCo-Warp**：同一套 Isaac Lab 任务，换求解器。策略若两边成功率接近，说明没过拟合某一套接触模型。
- **观测域差距**：仿真里硬币位姿是真值；真机上你得用相机/跟踪估。这是上真机最痛的一项，和「多视角相机」是为同一件事准备的。

## 怎么判断训练在干活

1. `mean_reward` 往上走，但不一定等于「会了」。看 `success_rate` / `Episode_Reward/hold_ok`。
2. 某个奖励项永远是 0 → 死项（判定太严，或几何写错了）。用 **Reward 探针**。
3. 熵塌了、成功率不动 → 探索死了或奖励在打架。
4. 先把 Stage A 托稳，再开 Stage B。界面可以把 Hold 配方的 `chain` 指到 Transfer。
