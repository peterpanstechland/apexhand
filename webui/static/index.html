强化学习术语（最短版）

          
    
            
  • 环境 / 策略：环境是仿真里的手和物体；策略是那张神经网络，看观测、出动作。
    • 
            
  • 观测 / 动作：观测是策略看到的数字（关节、硬币位姿）；动作是 16 个主动关节的增量。
    • 
            
  • 奖励：每一步打的分。策略只追求「长期加起来最多」，所以权重互相抢戏。
    • 
            
  • 一局 episode：从重置到掉落/成功/超时。超时秒数在「规模与时长」。
    • 
            
  • PPO：一种比较稳的策略梯度。每次更新不允许策略跳太远（由 KL / clip 管着）。
    • 
            
  • γ / 熵 / KL：γ 决定看得多远；熵决定还敢不敢乱试；KL 是这次更新改了多少。
    • 
            
  • 域随机化：每个并行环境用略不同的质量/摩擦/刚度，逼策略别死记仿真。
